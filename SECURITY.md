# Security Policy

## Supported Versions
This project is under active development. Security fixes are released on the `master` branch.

## Reporting a Vulnerability
Please **do not** open public GitHub issues for suspected security vulnerabilities.

Instead, report privately by emailing:

- security@nanosamur.ai (preferred)

If that address is not yet available, contact the maintainers via GitHub.

When reporting, please include:
- a description of the issue and impact
- reproduction steps / proof-of-concept if available
- affected versions / commits

We will acknowledge receipt and work on a fix.
